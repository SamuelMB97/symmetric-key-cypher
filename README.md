#### Requirements:
Should run on base python without additional packages.

#### Function
To run from terminal:
    "python encode.py [your message] [your key]"

Message and key should both be hexadecimal with length 16.

Prints the message, key and the ciphertext like so:
M = 0123456789ABCDEF
K = 133457799BBCDFF1
C = 85E813540F0AB405
